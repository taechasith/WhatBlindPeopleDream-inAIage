# Limitations

The current results are exploratory automated candidate labels, not validated
semantic annotations. Human double coding is pending. The AI corpus has only 28
released examples and includes heterogeneous real-world tasks; it is not a
representative sample of any deployed AI system. BLV questions and AI
descriptions have different communicative roles, so cross-domain divergence is
not an error rate or a preference measure. DreamBank onset data supports
congenital versus adventitious/unspecified grouping but not a clean early-versus-
late onset contrast. No result demonstrates AI-caused dream change, neural
change, harm, safety improvement, or cognitive transfer.
