# Study 1 adjudication protocol

1. The data steward validates that two independent coder files are complete,
   locked, and blinded. Coders may not communicate about cases before lock.
2. Compute reliability without adjudication. Preserve original files unchanged.
3. Route only discordant or `9` cases to an adjudicator who remains blind to
   condition/order/source identity. The adjudicator receives the report, unit,
   code definitions, and anonymized rationales—not coder identities.
4. Record the adjudicated code, rationale, date, and adjudicator ID in a new
   file. Never overwrite independent codes.
5. The preregistered primary analysis uses adjudicated codes only after the
   reliability report is finalized. Sensitivity analyses use each coder's
   independent labels separately.
6. If coders discover a systematic ambiguity, append an amendment with examples;
   do not silently revise a code definition after seeing condition labels or
   outcomes.
