# Study 1 causal estimands

## Scope

Study 1 estimates effects of specific, controlled pre-sleep information
experiences on subsequent **reported** dream incorporation. It does not estimate
neural reorganization, enduring cognitive change, or the effect of all real-world
AI use by blind or low-vision people.

## Primary estimand: target-specific incorporation after AI exposure

| Element | Specification |
|---|---|
| Contrast | Explicitly delivered target semantic units versus matched, non-delivered decoy units within eligible reports from DAI and SAI nights. |
| What differs | Whether the unit was delivered in the pre-sleep target-scene information set. |
| Held constant | Participant, night/report, coding process, unit count, decoy construction, report prompt, TTS route, and target/decoy list presentation to blinded coders. |
| Target estimand | Within-report difference in probability that a semantic unit is coded exact/semantic incorporation when it belongs to the delivered target set rather than a matched decoy set. |
| What it answers | Whether described target information is represented in dream reports more often than a matched false-source semantic baseline. |
| What it cannot answer | An AI-versus-human effect, a general effect of language, whether the content caused a dream, whether every dreamer incorporated it, or cognitive/neural change. |
| Known confounds/limits | Generic concepts can appear spontaneously; decoys reduce but do not eliminate this; target salience and description content vary; dream reports are incomplete self-report. |

## Secondary estimand: participant steering

| Element | Specification |
|---|---|
| Contrast | DAI target-minus-decoy incorporation versus SAI target-minus-decoy incorporation. |
| What differs | User steering, question/answer trajectory, agency, total interaction structure, and potentially which target units are delivered. |
| Held constant | Scene family, TTS route, session envelope, report prompt, target/decoy coding, timing target, and participant crossover design. |
| Target estimand | Effect of the **participant-led AI information interaction package** on target-specific incorporation relative to default AI output. |
| What it answers | Whether a human-to-AI steering interaction changes the target-specific incorporation profile. |
| What it cannot answer | A pure effect of agency, question count, lexical wording, or length in isolation. |
| Known confounds/limits | SAI intentionally changes content, agency, and interaction duration; post hoc adjustment cannot turn this into a pure style effect. |

## Secondary comparator: source/output provenance

| Element | Specification |
|---|---|
| Contrast | DAI versus matched HUM reference-description target-minus-decoy contrast. |
| What differs | Frozen AI-generated versus independently human-authored description provenance/content, after matching constraints. |
| Held constant | Scene/marker design, TTS, exposure envelope, timing, report prompt, and coding. |
| Target estimand | Difference between the two pre-specified description packages, conditional on achieved matching. |
| What it answers | Whether the observed incorporation profile differs under these particular AI and human reference materials. |
| What it cannot answer | Superiority of AI or humans in general, a pure authorship-source effect if scripts differ, or accuracy/safety in real environments. |
| Known confounds/limits | Provenance cannot be blinded to participants without deception; residual style/content differences remain. |

## Active narrative comparator

| Element | Specification |
|---|---|
| Contrast | Target-scene DAI/SAI outcomes versus ANC session outcomes and ANC decoys. |
| What differs | Presence of scene-specific visual-to-language content versus matched non-scene audio. |
| Held constant | Pre-sleep audio exposure, TTS, timing target, generic reporting procedure, and session envelope. |
| Target estimand | Contextual evidence about whether target-specific effects exceed those expected from receiving any neutral pre-sleep audio. |
| What it answers | Whether scene-specific target information is distinguishable from non-scene audio context. |
| What it cannot answer | An AI-specific effect; ANC does not contain a matched scene description. |
| Known confounds/limits | Meaningful narrative content may itself incorporate into dreams; this is a contextual/secondary contrast. |

## Decision

The paper does **not** require an AI-versus-non-AI causal claim. The narrow,
identifiable primary contribution is target-specific incorporation following
controlled AI-mediated scene information. AI-versus-human and user-steering
comparisons are secondary and must retain their package-level interpretation.
