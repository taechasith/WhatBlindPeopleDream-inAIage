# Study 1 randomization

`MASTER_RANDOMIZATION_LOCKED.csv` contains 208 anonymous allocation slots, not
participant identities. It is generated by `code/generate_randomization.py` from
a four-condition Williams design crossed with a four-stimulus Williams design.

The design gives every slot each condition and stimulus exactly once, balances
every ordered condition carryover pair, and balances condition-by-stimulus cells.
A coordinator maps an enrolled pseudonymous study ID to the next allocation slot
without giving this file to dream coders. Any change after ethics approval or
preregistration is a protocol deviation.
