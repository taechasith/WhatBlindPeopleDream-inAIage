# Post-freeze anonymous manuscript renderer

`code/32_render_anonymous_chi_manuscript.py` is intentionally inert until all
empirical and audit gates have passed. It generates anonymous LaTeX source; it
does not analyze data, choose an interesting result, write claims from raw
outputs, compile a PDF, or bypass the final CHI review checks.

## Preconditions

- A committed `RESULTS_FROZEN_PUBLIC_DATA_ONLY` receipt.
- A fact packet generated by `code/31_build_paper_fact_packet.py`.
- The final data-driven figure directory and manifest.
- An anonymous reference-audit JSON document with this minimum interface:

```json
{
  "status": "REFERENCE_AUDIT_CLEAN_ANONYMOUS",
  "results_freeze_sha256": "<sha256 of RESULTS_FREEZE.json>",
  "bibliography_sha256": "<sha256 of the audited .bib file>",
  "citations": [
    {"key": "AUDITED_BIBTEX_KEY", "verification_status": "PASS"}
  ]
}
```

- A completed, non-template render plan based only on fact IDs in the frozen
  packet. It must include all RQ2--RQ5 families, audited citation keys, and no
  more than twelve displayed result rows or three manuscript figures.

## Use after all prerequisites exist

```powershell
python code/32_render_anonymous_chi_manuscript.py `
  --results-freeze results/results_freeze/RESULTS_FREEZE.json `
  --fact-packet-dir paper/anonymous/generated `
  --figures-dir figures/final_public_data_v1 `
  --render-plan paper/anonymous/manuscript_render_plan.json `
  --citation-audit refs/FINAL_REFERENCE_AUDIT.json `
  --bibliography paper/anonymous/audited_references.bib `
  --outdir paper/anonymous/rendered
```

The output is created atomically and refuses to overwrite an existing render.
It includes a fact-level `CLAIM_TRACE.csv`, checksummed source manifest, copied
figure alt text, and a final PDF/anonymity checklist. Its result language is
fixed to computational/output-text statements and explicitly excludes causal
claims about dreams, cognition, brains, or lived experience.

The renderer does **not** certify the final page count. Build and inspect the
PDF only after rendering, then complete the final reference, claim, anonymity,
ethics, accessibility, and CHI-call audits.
