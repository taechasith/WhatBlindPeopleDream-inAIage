# Human coder return protocol v1.1

Return exactly two files: the completed supplied `coding_sheet.csv` and the
completed supplied `HUMAN_CODER_INDEPENDENCE_ATTESTATION_TEMPLATE_v1_1.csv`.
Use the assigned pseudonymous coder ID and copy the hashes from the supplied
assignment receipt. Do not edit `blind_item_id`, question, output, row order,
or schema. The coding lead preserves received originals unchanged and runs the
fail-closed lock tool. This protocol neither proves an attestation nor permits
condition access, synthetic labels, or LLM co-coding.
