# Public-intervention coding and adjudication protocol

1. Three independent coders receive separate blinded packets and code only the
   fields in `coder_template.csv` according to `PUBLIC_INTERVENTION_CODEBOOK_v1.md`.
2. Use `0`, `1`, or `NA`; do not turn `NA` into `0`. Preserve the independent
   records unchanged.
3. Calculate category-specific agreement before discussing disagreements.
   Preserve all three raw files and report prevalence, all pairwise percent
   agreement, pairwise chance-corrected coefficients, and a three-coder
   coefficient where estimable; mark degenerate categories `NOT_ESTIMABLE`.
4. Only after that calculation, adjudicate disagreements with a written
   rationale. The adjudicated table is not a substitute for the independent
   reliability record.
5. Coders may flag source privacy/sensitivity concerns and stop coding an item.
   Such a flag is handled under the secondary-data ethics plan, not silently
   removed.

No coder is told the prompt condition, model identity, hypothesized direction,
or original order. The coding assignment itself must be documented before labels
are inspected.

If only two genuine coder files are ultimately available, document
`ALT_TEST_TWO_HUMAN_LIMITATION`; no third file may be fabricated.
