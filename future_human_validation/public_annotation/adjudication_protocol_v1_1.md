# Public-intervention coding and adjudication protocol v1.1

Three independent coders use the supplied `coding_sheet.csv` and
`PUBLIC_INTERVENTION_CODEBOOK_v1_1.md`. Preserve independent `0`, `1`, and
`NA` records unchanged. Calculate and lock construct-level reliability before
any discussion. Only then adjudicate with a written rationale; adjudicated
labels never replace the raw reliability record. Coders receive no condition,
model identity, hypothesis direction, or original order. If two genuine coder
files are ultimately available, record `ALT_TEST_TWO_HUMAN_LIMITATION`; never
fabricate a third.
