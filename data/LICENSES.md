# Dataset license and access register

## VizWiz VQA

- Official annotation archive retrieved on 2026-10-05.
- Official VQA page states CC BY 4.0.
- This project acquired only the annotation JSON, not the image archives, because
  the registered BLV Intent analysis requires question text and answerability.

## DreamBank

- The live site states CC BY-NC-SA 4.0 and describes publicly accessible reports
  as anonymized.
- The blind-series page documents mixed onset histories. No record can enter an
  onset-specific corpus until its dreamer metadata is extracted and verified.

## Xie et al. CHI25 LMM released dataset documentation

- A local documentation snapshot was acquired on 2026-10-05 and is recorded in
  `data/MANIFEST.csv` and `data/CHECKSUMS.csv`.
- The repository license is recorded as Apache-2.0 in the manifest, but the
  snapshot contains source-derived accessibility descriptions and source-platform
  context. Treat that text as local-only unless an independent redistribution
  review establishes a broader permission.
- Do not distribute descriptions, screenshots, original links, or source images
  in anonymous review materials.

## GuideDog

- Public dataset metadata identifies CC BY-NC 4.0 and auto-approved gated access
  for non-commercial academic research, with a no-redistribution condition.
- The access request requires personal/institutional fields and explicit terms
  acceptance. No request was submitted and no gated data were downloaded because
  this workspace has no authorized requester identity. The public metadata is
  not treated as corpus data.

## Redistribution

Raw data remain ignored by Git. Authorized researchers must acquire sources
through their documented access routes; the repository does not automate or
bypass those access controls. No raw or text-bearing derived corpus may be
placed in an anonymous supplementary archive.
